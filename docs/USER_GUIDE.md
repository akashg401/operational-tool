# Operations Toolkit - User Guide

## Available Tools

### PDF Splitter

Splits combined PDFs into individual policy PDFs or invoices.

### PDF Merger

Merges multiple PDFs into a single PDF.

### Format CSV

Formats insurer/TMC files into portal-ready upload files.

Supports:

* Dolphin Portal
* Global Portal

### Download PDFs

Downloads policy PDFs directly from Asego policy reports.

Features:

* Individual download
* Hub-wise download
* ZIP export

### Merge Policy Reports

Combines multiple policy reports into one master report.

Features:

* Duplicate policy removal
* Hyperlink preservation
* Consolidated reporting

## Notes

* Upload only XLSX files where required.
* Hub-wise downloads require a Hub Name column.
* Error reports should be reviewed before upload.
* Dolphin exports generate portal-compatible XLSX files automatically.
